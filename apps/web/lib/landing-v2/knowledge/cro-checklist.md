🔥 ESTRUCTURA CRO DEFINITIVA —
CHECKLIST OBLIGATORIO
(Ordenada exactamente como una landing de alto rendimiento)

1️⃣ Hero / Gancho
(Captura atención en 3 segundos)

✔ Se entiende qué es
✔ Se entiende para quién es
✔ Dolor principal explícito
✔ Promesa clara (1 beneficio fuerte)
✔ Imagen o video orientado al resultado
✔ CTA visible arriba del fold

👉 Regla CRO: claridad > creatividad

2️⃣ Oferta Irresistible
(Hace que el precio tenga sentido)

✔ Qué incluye exactamente
✔ Precio anclado (antes vs ahora)
✔ Bonos visibles
✔ Ahorro explícito
✔ Valor percibido > precio

👉 El usuario debe sentir:
“Esto vale mucho más de lo que cuesta.”

3️⃣ Urgencia + Escasez
(Evita el “luego lo veo”)
✔ Fecha límite real
✔ Stock limitado visible
✔ Alta demanda (prueba social en tiempo real)
✔ Contador o indicador dinámico

📌 Sin urgencia = no hay decisión.

4️⃣ Antes y Después
(Visualiza el cambio)

✔ Estado actual (dolor, frustración)
✔ Estado deseado (resultado claro)
✔ Comparación directa
✔ Imagen, bullets o metáfora visual

👉 El cliente debe verse antes y después de comprar.

5️⃣ Beneficios
(Traducción emocional del producto)

✔ Beneficios, no características
✔ Lenguaje simple y concreto
✔ Resultados cotidianos
✔ 3–6 beneficios máximo
✔ Apoyo visual (íconos, gráficos)

📌 Pregunta clave:
¿Cómo mejora su vida?

6️⃣ Cómo Funciona
(Reduce fricción y confusión)

✔ Pasos simples (1–2–3)
✔ Qué hacer, cuándo y cómo
✔ Cuándo se ven resultados
✔ Qué NO necesita hacer

👉 Menos esfuerzo percibido = más CRO.

7️⃣ Tabla Comparativa
(Justifica la elección)

✔ Tú vs alternativa común
✔ Enfoque en seguridad, resultados y confianza
✔ Visual clara (checks / cruces)
✔ Ganas sin atacar directamente

📌 Ideal para clientes racionales.

8️⃣ Prueba de Autoridad
(Reduce el miedo a equivocarse)

✔ Marca registrada / respaldo
✔ Uso por miles de personas
✔ Procesos, certificaciones o control de calidad
✔ Mensaje de seguridad

👉 Autoridad = menos riesgo mental.

9️⃣ Testimonios
(Confirma la decisión)

✔ Reales y creíbles
✔ Lenguaje natural (no publicitario)
✔ Resultados específicos
✔ Contexto local (Perú)
✔ Diferentes perfiles de cliente

📌 Colócalos cerca del CTA.
🔟 Garantía / Riesgo Cero
(Elimina la última objeción)

✔ Garantía clara
✔ Tiempo definido
✔ Proceso simple
✔ Mensaje tranquilizador

👉 Si el riesgo es tuyo, el “sí” es fácil.

1️⃣1️⃣ Objeciones / FAQ
(Discute con la mente del cliente)

✔ ¿Y si no funciona?
✔ ¿Es seguro para mí?
✔ ¿Cuándo llega?
✔ ¿Para quién NO es?

📌 Sección invisible, pero clave para el CRO.

1️⃣2️⃣ CTA Final
(Cierre limpio)

✔ CTA fuerte y directo
✔ Recordatorio de beneficios
✔ Urgencia final
✔ Seguridad (pagos, envío, garantía)

👉 Aquí no se convence: se ejecuta.

1️⃣3️⃣ Elementos de Confianza (Transversales)
(Siempre visibles)

✔ Logos de métodos de pago
✔ Envíos claros
✔ Contra entrega (si aplica)
✔ Sin enlaces distractores
✔ Diseño limpio, rápido y legible

🧩 ESTRUCTURA COMPARTIDA ENTRE
LAS 3 (CLAVE PARA TU GPT)
Las 3 páginas, aunque diferentes visualmente, comparten el mismo esqueleto CRO:

1. Hero (promesa + dolor + resultado)
2. Beneficios inmediatos
3. Oferta + precio + packs
4. Reducción de fricción (envío / pago)
5. Beneficios ampliados (listas o razones)
6. Mecanismo / cómo funciona
7. Segmentación (para quién es)
8. Ingredientes / materiales
9. Cómo usarlo
10. Comparativa
11. Antes / Después
12. Testimonios
13. Autoridad (médica / legal / social)
14. Re-oferta final
