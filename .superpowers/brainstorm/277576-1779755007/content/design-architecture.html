↓ Blob URL guardado en sesión
2 Producto + preguntas upload + 3 campos → Gemini scan → ProductScan JSON
↓ Blob URL + answers guardados en sesión
3 Comentarios TikTok textarea → Gemini → CopyVersions {A, B}
↓ copy_versions JSON guardado en sesión
4 Elegir copy pick A/B → POST confirm → confirmed_copy guardado
↓ section 5 se desbloquea automáticamente
5 Generar anuncio SSE stream → Gemini editImage → Blob URL → resultado

Imagen para Gemini: Vercel Blob → base64

Gemini necesita bytes de imagen (no URLs). La solución: cuando se llame al API de Gemini, se hace fetch(blobUrl) → arrayBuffer() → base64 → inlineData Part. Las imágenes siguen almacenadas en Vercel Blob.
