Estructura del all-in-one page

¿Cómo deben comportarse las secciones del wizard al estar todas en una sola página?

✓ ACTIVO
📎 Referencia — analizada
→ EN CURSO
📦 Producto + preguntas
🔒 BLOQUEADO
💬 Comentarios TikTok
🔒 BLOQUEADO
✍️ Elegir copy
🔒 BLOQUEADO
✨ Generar anuncio

A — Todo visible, secciones bloqueadas

Todas las secciones están en pantalla desde el inicio. Las secciones futuras aparecen opacas con candado. El usuario ve el recorrido completo antes de empezar.

✓ ACTIVO
📎 Referencia — analizada
→ EN CURSO
📦 Producto + preguntas
↓ próximas secciones aparecen aquí al avanzar

B — Aparición progresiva (reveal)

Solo las secciones completadas y la activa son visibles. Cada sección nueva aparece con animación cuando se desbloquea. La página crece hacia abajo.

1. Referencia ✓ ▲
Anuncio analizado: ratio 9:16, TikTok, estilo lifestyle
2. Producto + preguntas → ▼
🔒 3. Comentarios TikTok
🔒 4. Copy
🔒 5. Generar

C — Acordeón (todo visible, colapsado)

Todas las secciones visibles como acordeón. Las completadas colapsan mostrando su resumen. La activa está expandida. Las bloqueadas se ven pero no abren.
