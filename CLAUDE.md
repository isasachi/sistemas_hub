# jr-ai-hub

Hub de tools de marketing con IA (Next.js 16 + Supabase). Las convenciones, las leyes que valen
en todo el repo y las prohibiciones ya medidas están en AGENTS.md — léelo antes de tocar código.

La doctrina de cada tool vive aparte, en `agents/<tool>.md`, y **no se carga sola**: AGENTS.md
tiene la tabla de qué archivo abrir según qué código vas a tocar. Abrilo antes de editar esa tool.
